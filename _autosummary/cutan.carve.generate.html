cutan.carve.generate

cutan.carve.generate¶

Generated art: a prompt in, a keyed, fitted, provenance-carrying plate or part out (cutan#100).

An image model draws a plate (a landscape, a car’s cabin) or a part; where the art must be see-through (a car’s windows) the prompt asks for a flat key colour, and that colour is keyed to alpha by cutan.carve’s own matte (the chroma strategy), its rim de-spilled, then the image is cover-fitted to the stage canvas and written as a PNG beside a record of where it came from.

>>> from PIL import Image
>>> def painter(prompt, *, size, background, quality=None, model=None):
...     im = Image.new("RGB", (64, 48), (246, 3, 242))      # the magenta key
...     im.paste((40, 110, 200), (16, 12, 48, 36))          # the subject
...     return im
>>> painter.provider, painter.model, painter.license = "test", "toy", "cc0-1.0"
>>> import tempfile
>>> made = generate_art({"box": {"prompt": "a blue box", "key": "magenta", "fit": [32, 24]}},
...                     out_dir=tempfile.mkdtemp(), generator=painter)
>>> made[0].path.name, made[0].size, made[0].source.license
('box.png', (32, 24), 'cc0-1.0')

  • The spec (art_specs()): {name: {prompt, size, background, key, fit, model, quality}}, a mapping or a JSON file. background: "opaque" or "transparent" (the model’s own alpha, where it has one); key: a named key colour (KEYS, "magenta") or any matte recipe as_matte() reads; fit: [w, h], scale to

    cover and centre-crop.

  • The generator is the seam: generator(prompt, *, size, background, quality, model) -> PIL image, carrying provider, model and license for the provenance. The default, AixGenerator, calls the fleet’s aix.generate_image() (OpenAI’s gpt-image models by default; pip install "cutan[generate]").

  • The record: each image’s AssetSource (provider, model, prompt, licence) goes into art_sources.json beside the PNGs, to be set as the plane’s or the prop’s source so an credits can say where the picture came from.

Needs OpenCV for the key (cutan[carve]) and aix for the default generator; nothing here is imported by import cutan.

cutan.carve.generate.KEYS: dict[str, dict[str, Any]] = {'green': {'hue': [90.0, 150.0], 'matte': 'chroma', 'min_sat': 0.5, 'min_val': 0.4}, 'magenta': {'hue': [280.0, 322.0], 'matte': 'chroma', 'min_sat': 0.5, 'min_val': 0.4}}¶

a hue band in degrees, and only saturated, bright pixels in it. Magenta survives gpt-image’s anti-aliasing as roughly (246, 3, 242), hue 301; the band is narrow and the floors high so orchid, lavender, deep pink and violet in the subject stay. A subject in strong purple or magenta itself is keyed: keep those colours out of art that uses the key (or key "green").

Type:

Named key colours, as the chroma matte’s recipe

cutan.carve.generate.generate_art(spec, *, out_dir, generator=None, only=None, keep_raw=False, overwrite=False)[source]¶

Generate, key, fit and write each image of spec into out_dir.

Each image is <name>.png; art_sources.json (SOURCES_FILE) maps each file to its provenance (with the PNG’s sha256), merged with what the folder holds and written after every image. only: the names to make (default all). An existing <name>.png is kept, not paid for again, unless overwrite, so a batch that failed half way is resumed by running it again. The model’s own image is written first as <name>.raw.png, with its record, and removed once the PNG and its record are written, unless keep_raw: a key or fit that fails leaves the paid-for image, and the next run keys that image instead of paying for a new one. Every file is written whole or not at all.

Return type:

list[GeneratedArt]
